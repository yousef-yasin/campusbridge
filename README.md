# CampusBridge

An AI-powered accessible university learning platform for students with hearing, visual, and speech disabilities.

## Project Teams

### Web Development Team
Responsible for frontend, backend, database, and API integration.

### AI Development Team
Responsible for speech processing, lecture summarization, AI academic assistance, and intelligent learning features.

## Repository Structure

- web/ - Website development.
- ai/ - Artificial intelligence modules.
- docs/ - Shared project documentation.
