# Samples

No Arabic/Jordanian lecture audio is included yet.

Place test recordings here (`.wav`, `.mp3`, `.m4a`, `.ogg`, `.flac`, `.webm`), ideally with a
matching reference transcript (`<name>.ref.txt`, UTF-8) for manual accuracy review.
`tests/test_samples.py` runs the real model on every audio file in this folder.

Only add recordings you have consent to use; do not commit private lecture audio.
